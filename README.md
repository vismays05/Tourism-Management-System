# 🌍 Tourism Management System

A web-based **Tourism Management System** developed to simplify and manage travel-related activities such as tour packages, user registrations, bookings, and administrative operations.

## 🚀 Features

### User Side

* User Registration and Login
* Browse Available Tour Packages
* View Package Details
* Book Tour Packages
* Manage User Profile
* View Booking History
* Submit Queries and Feedback

### Admin Side

* Secure Admin Login
* Manage Tour Packages
* Add, Update, and Delete Packages
* Manage User Bookings
* View Registered Users
* Manage User Queries
* Dashboard for Administrative Operations

## 🛠️ Technologies Used

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** PHP
* **Database:** MySQL
* **Server Environment:** XAMPP

## ⚙️ Installation and Setup

### Prerequisites

Make sure the following software is installed:

* XAMPP
* PHP
* MySQL
* Web Browser

### Steps

1. Clone the repository:

```bash
git clone https://github.com/your-username/tourism-management-system.git
```

2. Move the project folder to:

```text
C:\xampp\htdocs\
```

3. Start **Apache** and **MySQL** from the XAMPP Control Panel.

4. Open phpMyAdmin:

http://localhost/phpmyadmin

5. Create the required database and import the provided SQL file.

6. Open the application in your browser:

http://localhost/tourism-management-system/

### Admin Panel

http://localhost/tourism-management-system/admin/
